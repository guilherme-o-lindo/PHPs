# Exercícios de Lógica em PHP

Repositório com uma coleção de exercícios de lógica de programação desenvolvidos em **PHP**.

Os exercícios têm como objetivo praticar conceitos fundamentais de programação e desenvolver o raciocínio lógico através de diferentes problemas e situações.

## 📚 Conteúdos praticados

- Variáveis e constantes
- Operadores matemáticos e lógicos
- Estruturas condicionais (`if`, `else`, `elseif`)
- Estruturas de repetição (`for`, `while`, `do while`)
- Arrays
- Funções
- Manipulação de strings
- Entrada e saída de dados
- Operações matemáticas
- Resolução de problemas lógicos
